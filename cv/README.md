# Your CV goes here

Drop your CV into this folder as a **PDF** (any file name, e.g. `my-cv.pdf`).

- The "Download CV" buttons on the site appear automatically once a PDF is here, and stay hidden while the folder is empty.
- Visitors download it as `Zikra-Abdusemed-CV.pdf`, whatever the file is called here.
- To update it, replace the file (or add a newer one: the most recently modified PDF wins).
